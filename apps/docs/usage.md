# Vue Stripe by the numbers

Vue Stripe has been on npm since 2017, first as `vue-stripe-checkout` and since 2021 as `@vue-stripe/vue-stripe`. Every number on this page comes from a public source: the npm download counts, the GitHub API and jsDelivr. The site fetches them when it is built, and your browser fetches them again when you open the page.

## About these numbers

- **npm downloads are a trend, not a count of users.** npm counts every install of the package, including CI runs, Docker builds, registry mirrors and bots, and it does not count installs served from a cache. Read the numbers as a measure of how much the package is used, not of how many people or apps use it.
- **All-time totals** add up npm's daily counts from the day each package was first published: `@vue-stripe/vue-stripe` on January 6, 2021 and its predecessor `vue-stripe-checkout` on September 27, 2017. The unscoped `vue-stripe` package on npm belongs to a different author and is not counted.
- **Contributors** counts every GitHub account that has committed to the repository, plus commit authors without a GitHub account.
- **CDN hits** are the requests jsDelivr served for the package's files, mostly from pages that load the UMD build with a `<script>` tag.
- **Dependents** are not in the GitHub API, so the page links to [GitHub's dependents list](https://github.com/vue-stripe/vue-stripe/network/dependents) instead of showing a number.
- **Stripe sees Vue Stripe apps too.** Apps built with Vue Stripe identify themselves to Stripe through Stripe's partner program, so Stripe can tell Vue Stripe integrations apart in its own data. Those numbers are Stripe's and are not published here.
